# Codex API 生图与改图

使用本 skill 自带的 `scripts/imagegen.py`，直接复用这台电脑 Codex 的 API provider，不要求用户重新填写已有密钥。默认编排模型 `gpt-6.1-sol`，图片模型 `gpt-image-2`；不要因为对话正在使用别的模型而改变这两个默认值。用户明确指定模型时才用参数覆盖。

## 执行

默认走“直接生成 → 直接交付”。用户描述足够明确就执行，不为构图、画幅等可合理决定的细节追问；不要把日常生图变成环境检查或排障任务。

1. 复用已知可用的 **Python 3.11+**；如果尚不知道可用路径，优先定位客户端自带运行时，只确认一次，不逐个试用旧系统Python。脚本只依赖标准库，无需安装SDK或预读脚本源码。
2. **直接运行generate/edit，不先运行inspect、--help或重复版本检查。** 脚本会自行读取当前配置并报告缺项。inspect仅用于安装验收、用户要求检查配置或实际配置故障；已确认的信息在当前会话复用，不额外探测其它图片工具或接口。
3. 新图用generate；改图用edit并传入原图--image，最多三张参考图。使用简短、具体的提示词，不擅自扩写成大量细节；改图说明保留项，文字逐字引用。仅复杂引号或较长提示词才用临时UTF-8文件与--prompt-file。
4. 输出到当前工作区有意义的新文件名，默认output/imagegen/。一次请求一张，默认medium；用户明确要快速草图时才用low，不为加速擅自降低画质或更换模型。
5. 脚本确认completed且已保存图片后，**立即用绝对路径的Markdown图片展示真实输出**，无需再调用图片查看工具、列目录、读取文件属性或另做验收。用户明确要求检查、对比或结果异常时才追加必要检查。尺寸需要说明时直接使用脚本报告的实际尺寸。

首次生成就按已知网络权限申请必要权限，不先发受限请求试错，不另做DNS/TCP探测。等待同一个异步进程，避免密集查询；不因等待而重跑生成或反复读取源码。只有安装、配置缺失或实际错误才按需诊断，超时或完成不明时不自动重发。不要为常规生图新增测试、文档研究或配置排查；上级指令明确要求的步骤仍须遵守。

```sh
python "<本 skill 路径>/scripts/imagegen.py" generate --prompt "白底红苹果产品照片" --out "output/imagegen/apple.png"
python "<本 skill 路径>/scripts/imagegen.py" edit --image "door.png" --prompt "仅在门上添加贴着的白底黑字纸质门牌，文字为‘星河科技’，匹配透视和阴影，其余内容保持不变。" --out "output/imagegen/door-sign.png"
```

上述 `python` 代表第一步找到的运行时，不能假定所有系统的命令相同。

## 认证与接口

脚本读取活动 profile/provider 的 `base_url`，依次使用该 provider 的 `env_key`、`experimental_bearer_token`；官方 provider 或 `requires_openai_auth=true` 的 provider 也支持环境变量 `OPENAI_API_KEY` 和 `auth.json` 的 `OPENAI_API_KEY`。不把 ChatGPT OAuth 登录 token 当 API Key，不猜测其它服务的凭据，不修改 Codex 配置。

域名根地址自动补 `/v1/responses`；已有 `/v1` 或自定义 API 前缀则在其后加 `/responses`。脚本通过 Responses API 显式携带 `image_generation`、图片模型及 `tool_choice`，拒绝重定向。支持 SSE 和普通 JSON 返回；真正图片来自 `image_generation_call.result`，文字答复不算生图成功。

没有可用密钥时说明所缺的配置位置，不让用户把密钥粘贴到聊天。不要建议关闭整个沙箱。API 会消耗所配置服务的额度。

## 国内与海外网络

默认 `--dns auto` 先用系统解析，仅在直连公网 API 域名解析失败后并行尝试阿里 DNS 和 Cloudflare 的加密 DNS，采用先返回有效地址的来源；备用解析和连接均有限时。系统正常时不查第三方，已有代理/NO_PROXY照常使用，代理解析失败不绕过代理。

用户要求只用国内备用来源时选 `--dns cn`，只用海外来源选 `--dns global`；使用内部自定义域名或不允许第三方获知 API 域名时选 `--dns system`，关闭外部解析。备用查询仅含域名，不携带密钥/提示词/图片；本机/IP字面量和常见内部/保留后缀不外查，拒绝非公网IP。连接始终使用原 API 域名的 HTTPS 证书校验、SNI及Host，不改系统 DNS、不关闭校验、不重发已提交请求。DNS兜底不能解决沙箱权限、代理/服务端故障或区域访问限制，不承诺全球永不报错。

## 检查与交付

- 默认直接交付脚本保存的真实图片，使用绝对路径；无需额外打开验图。仅在用户要求或结果异常时检查内容、文字、透视及编辑保留项；不得用放大插值冒充实际分辨率。
- 只有脚本确认响应完成且保存了图片才能宣布成功。HTTP 200 或一段“已生成”的文字都不够。
- 请求超时、断流、5xx 或完成状态不明时，**不要自动重新提交**。保留已保存的图片和响应 ID（如果有），说明结果不确定，先核对中转记录，避免重复扣费。
- 脚本明确提示未发送生图请求时，DNS/连接权限/拒绝连接属于连接前失败，可在修复连接或获得所需权限后再提交；不额外探测或修改端点。DNS错误可能来自权限限制或实际配置/DNS故障，不能一律归因于沙箱。TLS证书错误应修复信任配置，不能关闭证书校验。模糊网络错误和超时仍按结果不确定处理。
- 明确的工具权限错误可能来自上游账号或分组调度。不能只凭一次失败断言模型不支持图片，也不能擅自换成更贵的模型、修改服务器账号或重试其它收费模型。
- 修改生成图时用新文件名保留原图。脚本参数 `--size`、`--quality`、`--output-format` 是请求值；实际成图可能不同，按检查结果如实说明。
